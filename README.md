### 🧭 About me

- 🎓 Studying Data Science at **UTEC**, currently writing my thesis on **urban crime analytics over Lima's road network** (TopoCrime).
- ⚙️ I work across the whole data lifecycle: ingestion, Spark pipelines, modeling and the interactive visualization at the end.
- 📊 I like turning big, messy public data (elections, public procurement, crime) into web visualizations people can explore.
- 🌱 Currently learning: **AWS** and LLM-based agents.
